¡Bienvenido al repositorio de **M5StickC Accuweather Watch**! 

Este proyecto convierte tu [M5StickC](https://m5stack.com/collections/m5-core/products/stick-c) en un reloj inteligente en miniatura que no solo te da la hora, sino que también muestra el **pronóstico del tiempo en tiempo real** utilizando la API de Accuweather. 

---

## ✨ Características

- 🕒 **Reloj Digital:** Muestra la hora actualizada a través de conexión WiFi (NTP).
- ⛅ **El Tiempo en Directo:** Obtiene datos actualizados del clima usando la API de Accuweather.
- 📡 **Conectividad WiFi:** Conexión inalámbrica a tu red local para actualizar la información de forma autónoma.
- 🔋 **Portátil y Compacto:** Aprovecha al máximo la pantalla y portabilidad del M5StickC.

---

## 🛠️ Requisitos

### Hardware
* Un dispositivo **M5StickC** de M5Stack.
* Cable USB Tipo-C (para programación y carga).

### Software
* [Arduino IDE](https://www.arduino.cc/en/software) (o VSCode con PlatformIO).
* Librerías de M5StickC instaladas en tu entorno de desarrollo.
* Una cuenta gratuita en el [Portal para Desarrolladores de Accuweather](https://developer.accuweather.com/) para obtener tu **API Key**.
